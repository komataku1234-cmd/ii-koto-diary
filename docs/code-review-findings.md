# コードレビュー指摘事項(未対応分)

`/code-review`でプロジェクト全体を対象に実施したレビューの指摘10件のうち、
以下の8件が未対応だった(うち#4・#5は、その後の管理者認証の強化で対応済み)。
対応済みの2件(コメントの削除取り消し機能・文字数上限の定数一本化)は
devlogおよびコミット履歴を参照。

## 1. `postId`等が無い時、`0`として扱われチェックをすり抜ける

**該当箇所**: `src/app/actions.ts`(`addReaction`・`createReply`)、`src/app/admin/actions.ts`の各Server Action

`Number(formData.get("postId"))`は、値が無い(`null`)場合`0`になり、`Number.isInteger(0)`は`true`と判定されるため、「不正なリクエストです」のチェックをすり抜けてしまう。

**起こりうる問題**: hidden inputが何らかの理由(改ざん・実装ミス)で無くなった場合、`postId=0`のままDB処理に進み、意図した優しいエラーではなく生のDBエラーが出る。

## 2. 削除済みの投稿にも、新しいリアクション・コメントが付けられてしまう

**該当箇所**: `src/app/actions.ts`(`addReaction`・`createReply`)

対象の投稿が削除済み(`deletedAt`)かどうかを一切チェックしていない。

**起こりうる問題**: 管理者が不適切な投稿を削除しても、そのページを開いたままの人・投稿IDを知っている人は、リアクションやコメントを送り続けられる。復元した時にそれらが全部残っている。

## 3. 削除済みの投稿を、URLを直接開けば編集できてしまう

**該当箇所**: `src/app/admin/actions.ts`(`updatePost`)

`updatePost`は`deletedAt`を確認していない。管理画面の一覧では削除済み投稿に「編集」リンクを出していないが、`/admin/posts/[id]/edit`に直接アクセスすれば編集・保存できてしまう。

## 4. 管理者ログインに、連続試行を防ぐ仕組みが無い【対応済み】

**対応**: 2026-09-25に、`LoginAttempt`テーブルによるIP単位の回数制限(15分間に5回を超えたらロック)を追加して解消した。以下は指摘当時の内容。

**該当箇所**: `src/app/admin/login/actions.ts`

パスワード照合が単純な文字列比較で、何回間違えてもロックされない。総当たり攻撃への耐性が無い状態。

## 5. 「12時間でログアウト」がサーバー側では保証されていない【対応済み】

**対応**: 2026-09-25に、認証をDBのセッション方式(`AdminSession`)に変更し、期限を`expiresAt`でサーバー側で確認するようにして解消した。ログアウトも追加した。以下は指摘当時の内容。

**該当箇所**: `src/lib/adminAuth.ts`

認証Cookieの中身は固定のハッシュ値で、発行時刻の記録が無いため、実際に12時間で切れる保証はブラウザのCookie設定(`maxAge`)だけに頼っている。もしそのハッシュ値が漏れたら、`curl`などブラウザを介さないアクセスでは無期限に有効なままになる。

## 6. 絵文字を入れると、見た目より文字数を多くカウントしてしまう

**該当箇所**: `src/app/post/actions.ts`・`src/app/actions.ts`・`src/app/admin/actions.ts`の文字数チェック

文字数チェックはJSの`.length`を使っているが、これは絵文字などを1文字を2として数えることがある(サロゲートペア)。このアプリはリアクションが絵文字中心なのに、投稿本文に絵文字を使うと、見た目より早く文字数制限に引っかかる可能性がある。

## 7. 投稿編集後、編集画面自体のキャッシュが更新されない(可能性あり)

**該当箇所**: `src/app/admin/actions.ts`(`updatePost`)

`updatePost`は`/admin`と`/`は更新するが、編集画面自体(`/admin/posts/[id]/edit`)は更新していない。保存後に戻ると、古い内容が表示される可能性がある。

## 8. 並び替えのプルダウンが、戻るボタンで表示と実態がズレる可能性(可能性あり)

**該当箇所**: `src/app/SearchSortForm.tsx`

並び替えを選んだ後にブラウザの「戻る」を押すと、実際の並び順は変わっているのに、プルダウンの見た目は前の選択のまま、という状態になりうる。
